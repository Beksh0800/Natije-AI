# 🎓 NÄTIJE AI

> **Интеллектуальная образовательная платформа для автоматической проверки ученических работ с использованием искусственного интеллекта.**

NÄTIJE AI — это SaaS-платформа, которая избавляет учителей от рутины при проверке домашних и контрольных работ. Платформа использует передовые модели ИИ (GPT-4o, Claude Sonnet) для анализа загруженных работ, поиска ошибок, формирования персонализированной обратной связи и рекомендаций для учеников. 

## ✨ Основные возможности (MVP)

### 👨‍🏫 Для учителя
- Создание классов и управление списком учеников.
- Загрузка работ учеников (поддержка PDF, DOCX, JPG, PNG до 20 МБ).
- Автоматизированная AI-проверка работ (выставление баллов, классификация ошибок).
- Просмотр подробной аналитики и истории проверок.

### 🧑‍🎓 Для ученика
- Личный кабинет с историей загруженных работ.
- Детализированный просмотр результатов: набранные баллы, найденные ошибки и их разбор.
- Персонализированные рекомендации от ИИ для улучшения результатов.

### 👪 Для родителя
- Мониторинг успеваемости и прогресса ребенка.
- Доступ к рекомендациям от ИИ.
- Просмотр истории проверок и динамики оценок.

## 🛠 Стек технологий

**Frontend:**
- ⚛️ React 19 + TypeScript
- ⚡ Vite
- 🎨 TailwindCSS
- 🛣️ React Router v7

**Backend & Services:**
- 🔥 Firebase (Authentication, Firestore, Storage, Cloud Functions)

**AI Интеграция:**
- 🤖 OpenRouter API
- Основная модель: **GPT-4o**
- Резервная модель: **Claude 3.5 Sonnet** (автоматический фоллбэк при ошибках)

## 🚀 Установка и запуск (Local Development)

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/natije-ai.git
cd natije-ai
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
Создайте файл `.env` в корне проекта и добавьте необходимые ключи для Firebase и OpenRouter API (см. `.env.example`).

4. Запустите сервер для разработки:
```bash
npm run dev
```

Платформа будет доступна по адресу `http://localhost:5173`.

## 📂 Структура базы данных (Firestore)
- `users`: Пользователи (учителя, ученики, родители).
- `classes`: Учебные классы, привязанные к учителям.
- `students`: Ученики с привязкой к классу и родителю.
- `submissions`: Загруженные работы и их статусы.
- `reviews`: Результаты AI-анализа (баллы, ошибки, фидбек).

## 🔒 Безопасность и ограничения
- Строгое разделение ролей (RBAC) через Firebase Security Rules.
- Поддерживаемые форматы файлов: `PDF`, `DOCX`, `JPG`, `PNG`, `JPEG`.
- Максимальный размер загружаемого файла: 20 МБ.
- AI-анализ завершается не более чем за 60 секунд.
